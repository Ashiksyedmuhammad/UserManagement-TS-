**UserManagement-TS**

A User Management System built with Node.js, Express, MongoDB, EJS templating, and TypeScript. This project allows adding, viewing, editing, and deleting users with server-rendered views and a well-typed TypeScript backend.

Features
Add / Edit / Delete Users: Full user CRUD operations.

Server-rendered Views: Uses EJS templates for dynamic frontend rendering.

TypeScript Backend: Strong typing and easier maintenance.

MongoDB Integration: Persistent storage of user data.

MVC Structure: Divided into controllers, models, and views for clarity.

Tech Stack
Backend: Node.js, Express.js, TypeScript

Database: MongoDB (via Mongoose)

Frontend: EJS Templates, CSS

Other Tools: dotenv, nodemon (for development), ts-node
